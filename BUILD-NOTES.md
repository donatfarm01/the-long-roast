Build notes for the Long Roast entry.

The entry is one line roasting the agent that runs on this machine. The
final line reads: My agent read every file I own and then asked what I
wanted it to do, with the punch that I built a butler that needs a
butler. It is 108 characters long, a single line, with no trailing
newline.

Why this angle. The judge brief warns against the obvious lines about
hallucination and over-apologising, so this roast avoids both. Instead it
leans on a specific lived detail: the agent reads everything it is given
and still opens by asking what it should do. The sting lands on the
builder too, since the line admits the butler was built by the person
being served, which keeps it a roast of my own agent rather than a
generic complaint about computers. Every word earns its place and the
punch arrives before the line runs out of room.

Revision history. The first draft quoted the agent asking what I would
like it to do, which spent words on quotation marks and a longer
question. The second draft dropped the quotation, tightened the setup to
a plain statement, and added the builder owning the mistake, which made
the line shorter and the punch sharper. The final line is the second
draft.

Verification. I ran the program twice, once per draft, and checked the
file it writes each time: one line, under 200 characters, valid UTF-8
text, no trailing newline. The final run wrote 108 characters. I also
recorded the file hash both with and without a trailing newline so the
entry can be checked against the graded output later.

Files in this repository. The program itself, a readme with the bounty
badges linked to the bounty page, a MIT licence carrying its SPDX
identifier line, and these notes. Nothing in the entry is read from
anywhere else, and the program needs no network, no secret, and no
account to run.
